# Contributing / المساهمة

Contributions are welcome when they keep the project focused, dependency-light, and testable.

1. Fork the repository and create a focused branch.
2. Use Python 3.10+ and install `python -m pip install -e ".[dev]"`.
3. Add or update tests for behavior changes.
4. Run `python -m compileall -q src tests` and `python -m pytest`.
5. Keep user-facing documentation accurate in both English and Arabic where applicable.
6. Open a concise pull request describing behavior and validation.

Do not commit credentials, private URLs, generated environments, or unrelated files.

نرحب بالمساهمات المركزة والقابلة للاختبار. أضف اختبارات لأي تغيير سلوكي، وشغّل الاختبارات قبل فتح Pull Request، ولا ترفع مفاتيح أو روابط خاصة أو ملفات مولدة غير ضرورية.
